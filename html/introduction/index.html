My Projects

Taysir (تيسير)

Taysir is a Python-based Quran application designed to make reading and navigating the Holy Quran easier. It allows users to read verses, listen to Quran recitations, and access Tafsir Al-Muyassar. The project combines programming with a practical application designed to help users.

Star (نجمة)

Star is an AI-powered customer service assistant concept that helps users navigate digital services. It combines voice, text, and visual guidance to make the customer experience easier and more interactive.

Muraqib (مراقب)

Muraqib is an AI-powered smart stadium security concept. It explores the use of computer vision to help identify potentially dangerous situations and improve safety in stadiums.
