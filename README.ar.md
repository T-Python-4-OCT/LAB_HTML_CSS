# مختبر HTML وCSS

خمسة مشاريع للواجهات باستخدام HTML وCSS وJavaScript.

## فتح الموقع

افتح [index.html](index.html) من هذا المجلد بالنقر عليه مرتين. لا تحتاج إلى Node.js أو تثبيت أو بناء أو خادم. احتفظ بالمجلدات معًا حتى تعمل الروابط والصور والخطوط المحلية.

## الخصائص

- تدعم الرئيسية ومقدمة CSS والمقال والسيرة الذاتية العربية والإنجليزية.
- لمقدمة HTML صفحتان منفصلتان [بالعربية](html/introduction/index.ar.html) و[بالإنجليزية](html/introduction/index.html)، من دون CSS أو JavaScript.
- تحتفظ لوحة التحكم بتصميمها الأصلي بالإنجليزية والبحث والتصفية والنوافذ التجريبية، ولا تتضمن وضعًا عربيًا.
- تتكرر حركة المشي في مقدمة CSS. اختر الرسم لإيقاف الحركة أو إعادة تشغيلها. يمنع تفضيل تقليل الحركة التشغيل التلقائي.
- تتضمن السيرة الذاتية الخبرات والتعليم والمشاريع المفصّلة، من دون أدوات للطباعة.
- تعمل معاينة النماذج محليًا، وعمليات الربط في لوحة التحكم تجريبية. لا تُرسل بيانات ولا يحدث اتصال بخدمات خارجية.
- تُحفظ التفضيلات وتغييرات لوحة التحكم عندما يتيح المتصفح التخزين المحلي. تختلف قواعد تخزين الملفات المحلية بين المتصفحات، وتبقى الصفحات قابلة للاستخدام دون حفظ الحالة.

## الملفات

يحتوي `assets/` على التنسيقات المشتركة وتبديل اللغة والخطوط المحلية وصورة عناصر لوحة التحكم. يحتوي كل مجلد مشروع على صفحته والملفات اللازمة لها. لا يحتاج الموقع إلى مدير حزم أو ملفات بناء.

## فحص التغييرات

افتح `index.html` وجرّب روابط المشاريع واللغتين عند توفرهما. غيّر حجم النافذة وافحص التنقل بلوحة المفاتيح والتحقق من النماذج والبحث والتصفية والنوافذ في لوحة التحكم.
